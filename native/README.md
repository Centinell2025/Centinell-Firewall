# Android isolation prototype
User-consented VpnService establishes IPv4 and IPv6 default routes and consumes routed packets without forwarding them. This intentionally interrupts connectivity while active. It does not inspect packet contents, implement selective ALLOW rules, or guarantee system-wide lockdown. Android may exempt some traffic. No remote VPN or data collection. Stop via app or notification.
Build: npm install; npx cap add android (first time); node scripts/install-native.mjs; npx cap sync android; npx cap open android. Test on a spare device: deny consent, accept consent, check IPv4/IPv6 connectivity, stop, confirm connectivity restored, revoke VPN from Settings, switch VPN provider, process death, notification action and reboot. No device or build verification yet. Review Play VPN and foreground-service policies before distributing.
